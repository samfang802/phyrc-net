# 研究任務：RC 柱損傷影像單幀生成器的架構重設計

你是一位熟悉生成模型（diffusion / flow matching / GAN）與小資料學習的研究助理。請**查閱論文（優先 2023–2026 的 arXiv、CVPR/ICCV/ECCV/NeurIPS/ICLR/ICML）**，替下面這個單幀條件生成器提出「大幅改架構」的候選方案，並評估每個方案在我的限制下是否可行。請用繁體中文回答，術語保留英文。

## 1. 題目

給一根鋼筋混凝土（RC）柱在反覆載重試驗中的遲滯迴圈（drift–force 序列），生成某個時刻柱面的損傷照片：裂縫、保護層剝落、鋼筋外露出現的位置與範圍要跟著迴圈走。損傷指標（DI）是事後從圖算的，不能當條件；柱編號、設計參數也不直接進生成器（避免背柱子）。

## 2. 目前的單幀模型（要被取代的）

- 像素空間 OT conditional flow matching，速度預測，min-SNR 加權；推論 Heun 30 步。
- 骨幹：ADM U-Net，通道寬 32，最底層用 VSS（Mamba）block，mid attention。
- 影像：128×128 灰階，CLAHE。Patch Diffusion 訓練（full/half/quarter = 0.5/0.3/0.2，帶 XY 座標通道）。
- 條件：一個物理向量（原本是凍結的雙向 GRU hidden state，1024 維、有效秩約 16；正在換成一個單向「損傷狀態編碼器」，256 維 state + 4 個損傷標量：強度比、勁度比、累積能量、最大 drift），經 Linear + LayerNorm、乘上初值 0 的可學閘門，加到時間嵌入，驅動每層 AdaGN。另有方向（柱面）one-hot、加載正負號。
- 另有一個 16×16 粗剝落遮罩預測器 M（逐格 BCE），用來做時序的「可畫區 / 鎖住區」混合。
- 這個單幀模型同時是時序模型（逐幀 refiner）的第 0 幀來源，所以新架構最好仍能輸出「給定條件的一張圖」，並容易接上「上一幀當條件」。

## 3. 資料與算力限制（非常重要）

- 訓練只有 **4 根柱、約 530 張**影像，彼此高度相似（相鄰幀平均絕對差約 0.02）；DI > 0.9 的高損傷幀只有約 61 張。val 1 根柱（R307），test 1 根柱（CTR1，軸力與箍筋比在訓練範圍之外，屬於外插）。
- 另有約 160 根柱的遲滯迴圈（無影像），可用於訓練條件編碼器或自監督。
- GPU：單張 24 GB A5000（偶爾 48 GB A6000），一次訓練希望在 1 天內。
- 影像是單一場景類型（柱面特寫，灰階），和自然影像有明顯 domain gap。

## 4. 目前量到的問題（test = CTR1，指標為 DINOv3 特徵）

| 指標 | 目前模型 | 對照 |
|---|---|---|
| KID global（越小越好） | 0.194 | 舊 cGAN 0.116（但它幾乎 mode collapse：同條件換噪聲只差約 3 灰階）；另一根真實柱 0.072 |
| 演進 corr（條件順序一致性） | 0.81 | 真實柱 0.83 |
| 演進 ratio（生成圖隨條件變化的幅度 / 真實） | 0.38 | 真實柱 0.53 |
| 鄰居對比（能不能分辨相鄰條件） | 0.41 | 真實 0.69 |

用白話說：
1. **真實感不足**：紋理（混凝土、裂縫邊緣、剝落斷面）不夠像，KID 落後 cGAN。
2. **對條件反應太弱**：損傷演進的幅度只有真實的七成左右，相鄰條件分不太開。
3. **高損傷時剝落破碎**：大片剝落畫成零碎塊，而不是連續的一大塊；位置大致對但形狀不對。
4. **外插差**：CTR1 的剝落被系統性低估約 0.2–0.35（面積比例），換條件編碼器只能有限改善。
5. 同一條件下樣本變異大（約 36 灰階），亮度/色調不穩。

已經試過、效果有限或不採用的：條件瓶頸 / PCA、g 的鄰幀混合增強、patch 機率排程、self-conditioning、cascade 128、paired bridge、FlowEdit/SDEdit、autoguidance/CFG 變體、ControlNet 式分支（用在時序上）。

## 5. 請你研究的方向（每個方向都要找具體論文，不要只講概念）

A. **借用大型預訓練先驗**：在極小領域資料上微調預訓練 diffusion / flow 模型（如 SD 系列、PixArt、SiT/DiT、FLUX 類），LoRA / adapter / 部分層微調；灰階、單一領域、128 px 該怎麼處理；非文字條件（連續物理向量、序列 token）如何注入（cross-attention token、AdaLN、in-context token）。在 24 GB 上的實際可行性。

B. **Latent 空間 + Transformer 骨幹**：自訓或借用 VAE / DC-AE 等 autoencoder，配 DiT / SiT / U-ViT / MMDiT；小資料下 transformer 是否反而更差；把物理條件改成「每個半循環一個 token 的序列」讓影像 token 直接 attend 歷史，而不是壓成單一向量。

C. **先結構後紋理（layout → texture）兩階段**：先由物理條件生成損傷語意圖（裂縫線、剝落區、鋼筋外露的 segmentation 或 SDF / 連續損傷場），再用 semantic image synthesis（SPADE、ControlNet、mask-conditioned diffusion 等）渲染紋理。重點找：能保證大區塊連續、形狀合理的 layout 生成方法，以及「損傷隨時間單調增長」的結構化表示。

D. **小資料下提升真實感的訓練技巧**（可接在任何骨幹上）：REPA / 表徵對齊（對齊 DINOv2/v3 特徵）、adversarial post-training / 判別器（Projected GAN、DINO 判別器、Diffusion-GAN、ADD 類）、DiffAugment / ADA、few-shot generation、retrieval-augmented diffusion（以物理狀態檢索最近訓練幀當額外條件）。

E. **加強條件跟隨與外插**：讓生成對連續條件更敏感、更單調（ordinal / contrastive 條件損失、guidance 變體、條件化 normalization 的替代方案）；compositional / 外插到條件範圍外的生成方法；physics-informed 或 sim-to-real（用數值模擬產生的損傷場當中介）的相關工作。

F. **領域相關工作**：結構損傷 / 裂縫 / 剝落影像生成或合成資料（土木、SHM、材料顯微、醫學影像進程生成如「疾病進程 / 老化」生成），看他們用什麼架構解決小資料與「隨嚴重度演進」的問題。

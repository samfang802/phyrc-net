# 時序生成：配對橋

這份接在 `FLOWEDIT_TEMPORAL.md` 後面。FlowEdit 把剝落的大致形狀畫出來了，高 DI 仍像很多張圖疊在一起。這裡記為什麼，以及下一條訓練該改成什麼。

## 疊影從哪來

單幀 G 的速度是「給這個 g，從高斯走到某一張圖」的條件期望。同一個 g 底下，裂縫可以畫在很多位置，期望就是這些位置的平均。

FlowEdit 在同一張噪聲上，用上一幀的 g 和這一幀的 g 各算一次速度，圖只加上這個差：

```text
z_src  = (1 - t) * noise + t * x_prev
z_tar  = x_edit + z_src - x_prev
x_edit = x_edit + dt * (v(z_tar, g_t) - v(z_src, g_prev))
```

格子和還沒壞的混凝土在相鄰兩幀裡幾乎畫在同一處。這時 `x_edit` 和 `x_prev` 對得上，`z_tar` 等於 `z_src`，兩個速度相減接近 0，像素留在原地。換物件的編輯能保住背景，靠的就是這一段相消。

剝落和裂縫沒有固定位置。單幀 G 沒有「這一條裂縫長在上一幀的同一條上」。`x_edit - x_prev` 在破壞區是整片對不齊的紋理，速度差變成從一組裂縫挪向另一組。六十幀累下去，對得上的格子還在，對不上的破壞變成這些位置的平均。高 DI 的破壞佔掉柱子的大部分，所以疊影集中在下面幾列。

從 t = 0.75 再用這一幀的 g 走幾步，是在已經平均過的圖上補一層裂縫，沒有把前面疊進去的位置收成同一條。圖在

`results/DamagePatternGeneration/CFMADM/1024-dadaGNsplit/inference_samples/overview_di_3_high_6x6_selfcondOFF_step_15000_ode30_refine0p75_mg.png`

局部對比從大約 10–21 回到 25–34，單幀是 28–56。平均灰階仍約 108，單幀約 147。

多抽幾張噪聲取平均，只會讓這塊平均更穩。要改的是路徑的兩端：兩端都釘在同一對真實幀上，速度的目標就是這一對的差。

## BBDM

Bo Li、Kaitao Xue、Bin Liu、Yu-Kun Lai，CVPR 2023。arXiv:2205.07680。

圖像到圖像的翻譯，常見做法是條件生成：前向過程仍從圖走到標準高斯，網路另外吃一張參考圖。BBDM 認為這樣沒有保證最後會落到配對的那張圖上。他們改成布朗橋。橋在兩個給定的端點之間走，中間的分布同時受起點和終點約束，不會落到 N(0, I)。

一對圖記成上一幀 x 和下一幀 y。論文的前向是

```text
x_t = (1 - m) * x + m * y + sqrt(δ) * ε
m   = t / T
δ   = 2 * m * (1 - m)
```

t = 0 是 x，t = T 是 y。δ 在兩端是 0，在中點是 0.5。原始布朗橋的方差是 t(T-t)/T，步數一多，中點方差會大到訓不起來，所以他們把中點收到這個式子。網路預測的是橋上的漂移，不是「從高斯還原 y、再把 x 當額外條件」。

他們在 VQGAN 的 latent 裡做這件事，用來加速，也用來對付素描和照片這種差很遠的兩個域。參考圖只作為橋的一個端點，不再灌進每一層交叉注意力。

對到這裡：端點的想法對。我們的前後幀是同一根柱、像素對齊的照片，不是兩個域。中點方差 0.5 會把兩邊都有的格子和舊裂縫洗掉，模型又得重畫，疊影會回來。VQGAN 這裡沒有，也不加。

## I²SB

Guan-Horng Liu、Arash Vahdat、De-An Huang、Evangelos A. Theodorou、Weili Nie、Anima Anandkumar，ICML 2023。arXiv:2302.05872。

Image-to-Image Schrödinger Bridge。給兩個分布的成對樣本，直接學它們之間的非線性擴散橋。邊際在邊界對給定時有解析形式，所以訓練不必先把整條橋模擬出來，可以沿用擴散模型的抽樣方式。

論文做的是修復：模糊、低解析度、遮擋、JPEG 的圖走到清晰圖。退化圖裡已經有的結構留在橋上，當作重建的先驗。他們在 ImageNet 256 上超過把退化圖當條件、仍從高斯出發的條件擴散，也接近那些還要知道退化算子的逆問題方法。

和 BBDM 同一類結論：起點若已經帶著要留的結構，就不該先洗成高斯再重畫。I²SB 的實作是分數模型、非線性橋，比我們現在的直線 OT 重。我們要的是「兩端釘住」這件事，速度場維持一個向量。

## MasaCtrl

Mingdeng Cao、Xintao Wang、Zhongang Qi、Ying Shan、Xiaohu Qie、Yinqiang Zheng，ICCV 2023。arXiv:2304.08465。

不重訓。把擴散 U-Net 的自注意力改成互注意力：這一幀出 query，上一幀出 key 和 value。這一幀因此會去上一幀裡找相近的局部紋理，身份和表面留住，姿勢和版面仍可以變。

他們不在所有層、所有時刻都換。太早換，目標的版面還沒形成，結果會黏在來源圖上。太晚換，內容已經定了，來源的紋理進不來。實際用在去噪的中後段，以及 U-Net 解碼器裡的自注意力。前景和背景若搶同一組 key，再用一張遮罩把 query 分開。

這能解釋「不要每幀重抽裂縫」：已經畫出來的紋理用注意力鎖住，而不是把兩個速度相減。我們的 U-Net 自注意力只在最底層，另外是 VSS，沒有 Stable Diffusion 那種一層層的自注意力。互注意力鎖不住細裂縫。這條不作為下一步。

## TokenFlow

Michal Geyer、Omer Bar-Tal、Shai Bagon、Tali Dekel，ICLR 2024。arXiv:2307.10373。

不重訓。給一支現成影片和一段新文字，用預訓練的文生圖擴散模型改這支影片，同時留下原來的版面和動作。他們的觀察是：畫面一致，要先讓擴散特徵在幀與幀之間一致。

做法是兩段輪流。先挑幾張關鍵幀，用現成的編輯方法（Plug-and-Play、SDEdit 等）依新文字改它們。再把原片自注意力特徵裡的最近鄰對應找出來，把關鍵幀改過的特徵沿著這個對應送到其餘幀。對應來自原片，所以編輯後的紋理會跟著原來的運動走，而不是每幀各畫一次。

我們沒有一支已經對齊的損傷影片可以拿來抽對應。要生成的就是這支影片。對應若從模型自己已經疊糊的幀裡找，鎖住的是糊影。這條不作為下一步。

## 採用的做法

用 BBDM 的兩端，不用它的中點大方差，也不進 VQGAN。速度仍是一個向量，損失仍是速度 MSE。

```text
z_t = (1 - t) * x_prev + t * x_next
v   = x_next - x_prev
```

t = 0 是真實上一幀，t = 1 是真實下一幀。上一幀裡的格子和舊裂縫在整條路徑上都在。目標只剩這一對照片新長出來的差，不是兩個 g 各自的條件期望再相減。

g 和 Patch 的 XY 照舊進 split gated AdaGN。DI、柱編號、靜態設計參數仍不進生成器。

第一幀沒有上一幀，仍用現在的單幀 G，從高斯畫。單幀那張高 DI 6×6 目前仍是最清楚的單張。

推論時上一幀是模型自己的圖。訓練時給真實上一幀加一小點噪聲，橋才不會只見過完美的真實圖。這是 Diffusion Forcing 的用法：擾動打在觀測上，不在訓練迴圈裡跑 30 步 Heun。

M 不拿來當哪裡可以改的開關。疊影是目標本身是很多張圖的平均，不是遮罩畫窄了。

## 程式

`USE_PAIRED_BRIDGE=True` 時 `job/DamagePatternGeneration/train_ADMCFM.sh` 關掉 M，並從單幀 `chjqbp9m` 初始化。上一幀的混合係數最大 0.15，只在訓練時抽。沒有上一幀的樣本仍走高斯到圖。

損失在 `paired_bridge_flow_matching_loss`。推論是 `sample_paired_bridge_sequence`：第一幀從噪聲積分，後面每一幀的起點是上一幀的輸出。高 DI 6×6 用 `--spall_panel mg`，checkpoint 自己的 `use_paired_bridge` 會走這條，不畫 M。

| refiner、oracle | 見下方「殘差時序 refiner」「Oracle 上限」兩節                                                                                       | K = 8   |


**cGAN 為什麼只能用存檔圖（K = 1）。** 推論程式已經接好（`scripts/eval/generate_cgan_samples.py`、`src/model/legacy_cgan.py`），但不能用來重新生成 cGAN 的樣本：

- cGAN 的條件是 GRU 的隱狀態。checkpoint 記錄的 GRU（`HystereticGRU/2026-04-17_01-26-41`）已經不在，現有的 `phase1_extractor` 是另一個 GRU。用它生成的圖和存檔圖對不上（DINOv3 排名等於隨機），drift 演進的 corr 也只有 0.18（存檔圖是 0.69）。
- 反推條件、讓 G 重現存檔圖是可行的：換新的 z，與存檔圖平均只差 2.8 個灰階，排名中位數 2。所以 G 本身沒問題，問題只在 GRU。
- 換 z 只讓 cGAN 的輸出改變約 3 個灰階；我們的模型同一條件兩張圖平均差約 36 個灰階。cGAN 每個條件幾乎只會畫一張圖，所以 K = 1 的存檔圖已經代表它全部的輸出，多抽樣也沒有用。
- 另外，BatchNorm 的 running statistics 不能用：eval 模式下，每個輸入都只輸出同一張灰色平面。推論時要改用 batch statistics。

## 殘差時序 refiner

**模型**：`2026-10-13_03-02-40_refiner_res_15k`（`tlpg4q5l/checkpoints/last.ckpt`，15000 步），設計見 `docs/ARCHITECTURE_UPDATE_V10.md` 的 variant B。

- 每個面依 timestep 整條推進。第 0 幀由凍結的 gn（`chjqbp9m`）生成；之後每一幀把前一幀的狀態鎖在輸入通道，模型只預測殘差：S_t = clamp(S_{t−1} + 殘差)。條件另外加上 Δg（相鄰幀的 GRU 差）。
- 速度網路由 gn 的權重初始化（`velocity_init`）。
- 評估時用 `generate_eval_samples.py` 的 refiner 路徑：每個面整條推進，8 條軌跡在 batch 裡一起跑。

**對照組**


| 名稱        | 內容                                       | 用來回答                     |
| --------- | ---------------------------------------- | ------------------------ |
| gn        | refiner 的基底，逐幀獨立抽樣                       | refiner 比基底好多少           |
| gn_shared | gn，但同一條軌跡每一幀共用同一個初始雜訊（`--shared_noise`）  | 最便宜的連續化方法；refiner 至少要贏過它 |
| V9        | `selfcondnoDI`，有 self-conditioning 的單幀模型 | 目前最強的單幀模型（見下）            |


設定：test 和 val 各一次，K = 8。test 去干擾物並加安慰劑對照，val 只把參考集換成補圖版，作法和前面各節相同。結果在：

- `temporal.png` 畫出了每一幀的平均亮度：GT 幾乎是平的，每個模型都在 ±40 灰階間跳動；refiner 常衝到 220 以上。



### 偏亮與飽和偽影

- refiner 整體偏亮：test 平均 179（GT 159），val 171（GT 157）。
- 有 22%（test）和 18%（val）的幀整張平均亮度超過 200，GT 是 0%。這就是它飽和偽影 8% 的來源。
- 亮度沒有沿軌跡一路累積（`brightness_slope` −0.37，GT −0.44），而是隨機出現的尖峰。所以問題不是殘差越加越亮，而是某些幀的殘差一次把整張圖推亮。



### 結論與下一步

- refiner 是目前在單幀品質和條件一致性上最好的模型，兩根柱都能重現。
- 但它設計上要解決的時序一致性只做到一半，而且輸給「共用雜訊」這個免費的對照。主要原因是**色調沒有被前一幀鎖住**。
- 值得試：
  - 推論時把初始雜訊也沿軌跡共用，或部分共用（refiner 加 gn_shared 的做法）；
  - 約束殘差的整體平均（例如殘差去均值，或對色調變化加損失）；
  - 找出 S_t 過曝的那些幀，看是不是 clamp 之後還被推高。

# 損傷圖生成：目前架構

實作以 `job/DamagePatternGeneration/train_ADMCFM.sh` 和 `src/model/cfm/` 為準。資料分割是 `Data/DamagePattern/id_list_val_R307.json`。高 DI 的 test 6×6 用 CTR1，格子順序鎖在 `2026-09-20_21-48-32` 那張 overview 的 `items`。

## 題目

給一根 RC 柱的遲滯迴圈，生成對應時刻的損傷照片。生成要跟著迴圈走：裂縫、剝落出現的位置和大致範圍。DI 事後才由圖算出來，不當作生成條件。柱編號和靜態設計參數也不進生成器，避免模型背某一根柱。

## 生成器 G

像素空間的 OT conditional flow matching。骨幹是 ADM U-Net，通道寬 32，最底層 L3/U3 用 VSS。圖是 128×128 灰階，並做 CLAHE。訓練 15000 step，batch 128。推論是 Heun、30 步。

```
z_t = (1 - t) * z_0 + t * z_1
v   = z_1 - z_0
```

t = 0 是高斯噪聲，t = 1 是真實圖。網路只預測速度 v，損失是速度 MSE，再乘 min-SNR。z1_hat = z_t + (1 - t) * v 只是由速度還原畫面。

條件用 split gated AdaGN：

- g：凍結的 Hysteretic GRU hidden state，1024 維，再經 `Linear(1024 → 128)`。有效秩大約 16。目前腳本的 g dropout 是 0。
- 位置：Patch Diffusion 的 XY。裁切比例 0.5 / 0.3 / 0.2，座標跟著裁切走。
- 方向留在 scalar 路徑。DI 通道關掉。

另外有一張物件／鋼筋遮罩當 U-Net 的條件通道。它是鋼筋白線，不是柱子輪廓，不能用來去掉畫面邊緣的黑背景。

G 多看兩個通道：上一幀的粗亮度，以及這一幀要畫的範圍。這兩個通道的 `in_conv` 權重從 0 開始。要畫的範圍在新路徑裡是羽化後的連續權重，不是硬的 0/1。

## 粗遮罩 M

M 預測 16×16 的累積暗區，是逐格二元分類，不是像素，也不是速度。約為兩組小卷積加一個標量開關：

```
logit = conv(pool(x_{t-1})) + s(g) * conv(x, y)
s(g)  = sigmoid(Linear([g_{t-1}; g_t]))
```

s(g) 每一格共用。權重初值 0，bias 為 −2，所以一開始 s 約 0.12。上一幀的亮度池化不經過開關，可以標出已經暗的區域。座標那一路乘上 s 之後才加進去。g 不廣播進每一層卷積。

沒有上一幀時，pool 和 g_{t-1} 都是 0。訓練時 pool 加 N(0, 0.05)。10% 的 g dropout 若打開，只作用在 G，不作用在 M。

目前拿來訓 G 的 M 是凍結的，權重來自

`results/DamagePatternGeneration/CFMADM/2026-10-01_12-04-28/.../ixmlkm6l/checkpoints/last.ckpt`

（mask-only，2000 step）。

### m* 怎麼算

m* 是標籤，不是網路輸出。m 是 sigmoid 之後的機率。

1. 圖縮到 128、轉灰、CLAHE。亮度 L 在 0 到 1，換成 z = 2L - 1。
2. 16×16 每一格是 8×8 像素的平均。
3. 這一張圖的粗格 70% 分位當成混凝土背景，平移到 +0.3。
4. 種子是對齊後亮度 < −0.2（`dark_level 0` 再減 `seed_margin 0.2`）。只留最大的一塊連通種子。種子的上緣是寬度至少 4 格的最高那一列，單格尖刺不能把整張往上抬。
5. 對齊後亮度 < 0 的格子，只有貼著這塊種子、而且不高於這條上緣，才算進去。種子上方不塗。
6. 區域裡的洞補上。底部若被一條很矮的亮縫切斷（最多 2 格，而且旁邊那一列已經接到地面），才把縫補上。
7. 左右最外一列、而且比對齊後的混凝土還暗超過 0.55 的格子，當成拍進來的黑背景，清掉。底邊不套這條，避免切掉底部剝落。

沒有每張圖除以 max。

M 的損失是 BCE。這一幀才變成 1、上一幀還是 0 的格子權重 8，其餘權重 1。TV 權重是 0。

## G 怎麼用 M

`spall_soft_paint=True` 是現在要訓的路徑。`train_ADMCFM.sh` 已打開它，並把 `spall_cond_prob` 設成 False。M 仍凍結，權重是上面的 `ixmlkm6l`。G 從頭訓。舊的兩個 step 15000 結果還在，推論預設不走這條，所以舊 checkpoint 的評估不會被這次改動換掉。

要畫的粗格，是「被鎖的格子」以外的所有格子。被鎖的格子（沿用上一幀）有三類，其中第三類只在鎖健康區時才有：

- 上一幀的 m*（已經是剝落），兩個版本都鎖。
- 左右最外一列的黑背景，規則和 m* 相同，兩個版本都鎖。
- 健康混凝土：上一幀粗格亮度不低於該幀自己的 70% 分位再減 0.10。**只在 `spall_lock_healthy=True`（預設）時鎖。** 這個版本裡，比混凝土暗、又還沒進這一幀實心剝落的格子不鎖，裂縫可以跟著 g 重畫。`spall_lock_healthy=False` 時這一類不鎖，健康混凝土的格子也都歸可畫區，由 G 照 g 重畫。

所以：

| | 可畫區 |
|---|---|
| 鎖健康區（預設） | 這一幀的實心剝落範圍，加上比混凝土暗、還沒被鎖的格子（裂縫區） |
| 不鎖健康區 | 整張圖，扣掉舊剝落和左右黑背景 |

這一幀的實心範圍是 `solidify_extent`（m ≥ 0.5，3×3 closing，補洞，不上緣以上）。落在這個範圍裡的格子，在鎖健康區時不受健康規則鎖住，所以新剝落要畫；在不鎖健康區時本來就沒有健康規則，這句話不影響結果。兩個版本都一樣：舊剝落即使被包在實心範圍裡也鎖住。

這個 0/1 圖先最近鄰放大。可畫區內部保持 1，再以 sigma = 4 的高斯只往外加一圈尾巴。這張連續圖記成 α，同時做三件事：

- G 的第二個通道就是 α。第一個通道仍是上一幀粗亮度。
- ODE 每一步

```
z_t = α * z_generate + (1 - α) * z_locked
z_locked = (1 - t) * noise + t * x_prev
```

- 速度損失用同一條路徑的終點。可畫區的目標是這一幀，鎖住區的目標是上一幀，邊界按 α 混合。損失對 α 做加權平均，鎖住的像素不把新剝落環的誤差稀釋掉。沒有上一幀時 α 條件是 0，整張圖照常生成。

M 的 BCE 只用真實上一幀和真實這一幀。G 在訓練時看到的上一幀會沿 OT 路徑往噪聲推一點，混合係數在 0 到 0.15 之間隨機。推論時上一幀是 G 自己的圖，不再加這層噪聲。

先前兩次 step 15000：

- 整張機率（`04xr7xt9`）：第二通道是 M 的 sigmoid，不鎖像素。格子和裂縫被洗成灰。
- 增量並硬鎖（`fkyh8olv`）：推論用實心範圍，訓練用細的增量環，鎖是硬切。格子還在，高 DI 仍碎。訓練和推論的條件不一致。

測試 6×6 的閉環是每一幀的上一幀用 G 自己的輸出。格子順序不是時間序。

## 鎖健康區 vs 不鎖健康區

「G 怎麼用 M」同時涵蓋兩個版本；預設是鎖健康區（`spall_lock_healthy=True`）。不鎖健康區（`spall_lock_healthy=False`）也已經訓練過，這一節把兩者並排比較。

### 差別只在「哪些格子被鎖」

| | 鎖健康區（`True`） | 不鎖健康區（`False`） |
|---|---|---|
| 被鎖（沿用上一幀）的粗格 | 上一幀 m*（舊剝落）、左右最外一列黑背景、**健康混凝土** | 上一幀 m*（舊剝落）、左右最外一列黑背景 |
| 健康混凝土 | 上一幀粗格亮度不低於該幀 p70 − 0.10 的格子都鎖住，這裡的裂縫和亮度沿用上一幀 | 不鎖，這些格子由 G 照 g 重新畫 |
| 其餘機制 | 相同：α 羽化、ODE 每步混合 `α·z_generate + (1−α)·z_locked`、速度損失沿同一條路徑、上一幀擾動最大 0.15 | 同左 |

不鎖時，可畫區變得很大：整張圖除了舊剝落和黑背景，都是可畫區。所以新裂縫、裂縫重畫、亮度變化都可能出現在任何位置，不再只出現在剝落範圍裡。

### 目視觀察（我看了兩個 run 的 `_mg.png`，沒有量化指標）

- **鎖健康區：** 36 格幾乎一樣的灰色底，格線細，幾乎沒有裂縫；只在底部出現小塊亮斑，只有一格出現大面積剝落。整體看起來是同一張圖被稍微改動，生成不太跟著 g 變化。

這只是目視，沒有 DI 一致性或其他指標，不能說哪個版本比較準；只能說不鎖時畫面隨 g 的變化比鎖的版本大。

## 參考了什麼論文

**MaskFlow**（Xu、Yong、Yang、Gong、Lv，arXiv:2608.06929）。區域編輯的 flow。遮罩寫進機率路徑：可編輯區走向目標圖，外面用同一個噪聲走向來源圖。損失只落在可編輯區，並按面積把小遮罩的權重拉回來。另外有 Soft-Poisson：每一步用高斯軟遮罩解一個梯度域方程，改寫速度，把接縫抹平。他們的消融是路徑先把區域對準，Poisson 再補一點邊界。

**Blend-Aware Latent Diffusion**（Liu 等人，CVPR 2026 Findings）。診斷和這裡一樣：推論每步把保留區貼回去，訓練卻假設整張圖來自同一條乾淨路徑，邊界就變成兩塊分布接在一起。做法是訓練時模擬這次混合，讓去噪器直接學混合後的狀態。另一半是改 VAE，讓解碼器吃混合過的 latent。這裡沒有 VAE。

**Restora-Flow**（Hadzic 等人，WACV 2026，arXiv:2511.20152）。不重訓。硬遮罩把已知區貼上 flow 之後，每步多一次速度前向，把樣本拉回資料流形再加噪。他們寫明只貼、不重訓時，邊界會離開訓練分布。遮罩是 0/1。比 RePaint 快，因為不做反覆前跳。

**RePaint**（Lugmayr 等人，CVPR 2022）。已知像素每步按當前噪聲等級貼回。硬貼會在邊界留下不協調，所以他們把結果再加噪、倒退重採樣很多次。接縫換來大約十倍的步數。

**Diffusion Forcing**（Chen 等人，NeurIPS 2024）和 **MAGI**（Zhou 等人，CVPR 2025）。訓練不生成上一幀。真實上一幀各自加一個噪聲等級，模型學會在不乾淨的歷史上預測下一幀。推論時歷史是乾淨的，這個情況訓練分布裡有。MAGI 的噪聲打在觀測幀上，不增加網路次數。

**BAgger**（Po 等人，CVPR 2026，arXiv:2512.12080）。先讓模型自己走出長序列，再倒放當修正樣本，用原來的 flow 損失細調，不回傳整段梯度。每一輪都是完整 rollout。

健康區用分位數而不是絕對亮度，沒有對應的生成論文。它和 m* 已經在用的 p70 對齊是同一類光度規則。

## 這次採用的

採用 MaskFlow 的路徑，不採用 Soft-Poisson。採用 Blend-Aware 的「訓練要看見推論那次混合」，不改 VAE。上一幀的擾動採用 Diffusion Forcing / MAGI 的加噪，係數最大 0.15，每個訓練 step 都抽，不佔額外前向。M 的 BCE 不混進去。

不採用 RePaint 的重採樣、Restora-Flow 的每步額外修正，也不採用 BAgger 的長序列 rollout。

健康區門檻是該幀粗格 p70 減 0.10。p70 用被鎖的那一幀自己的，不用下一幀。`spall_lock_healthy=False` 時不鎖健康區，只留舊剝落和左右黑背景。預設是鎖上。兩個版本的比較見上一節「鎖健康區 vs 不鎖健康區」。

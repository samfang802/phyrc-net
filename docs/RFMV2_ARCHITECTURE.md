# rfmv2：視窗式自回歸重畫加規則記憶

rfmv2 是 v12 refiner 的新版本。它和 v12rfm 一樣用規則記憶（ILF-lite）和 Resampling Forcing，但改了三件事：

1. **訓練時 S 的誤差改成跨幀累積。** 原本每個樣本只重畫一張 t−1（平行重畫）；現在一次重畫一整段視窗，每一張讀前一張重畫結果（自回歸重畫）。
2. **記憶也從重畫的幀寫。** 訓練時記憶和推論時一樣，帶著模型自己的誤差。
3. **不教模型推翻歷史。** 歷史記憶裡有、真實序列裡沒有的結構，loss 降權。

本版不使用學出來的記憶編碼器 E（learned latent），記憶寫入規則和 v12rfm 相同。

---

## 1. 為什麼要改

### 1.1 推論時的誤差是累積的，訓練時看不到

rollout 探測（v12rfm 9k，val，每個目標幀 8 次抽樣）：從真實的 t−1−h 開始讓模型自己生成 h 幀，比較生成的 S_{t−1} 和真實的 t−1。

| S 的來源 | 低頻誤差 | 全域對比（相對真實） | 裂縫保留 | 假裂縫 | 記憶歸零後 loss 增加 |
|---|---|---|---|---|---|
| 推論，走 1 步 | 14.0 | 0.79 | 0.82 | 0.20 | +0.0027 |
| 推論，走 8 步 | 25.9 | 0.66 | 0.61 | 0.53 | +0.0061 |
| v12rfm 的訓練方式（平行重畫），任何 t_s | ≤ 13.2 | ≥ 0.76 | ≥ 0.80 | ≤ 0.18 | ≤ +0.0027 |
| 自回歸重畫 8 跳，t_s = 0.1 | 12.3 | 0.65 | 0.62 | 0.48 | +0.0055 |

- 平行重畫讀的永遠是真實的 t−2，所以最多只能模擬走 1 步的誤差。
- 自回歸重畫在 t_s ≈ 0.1 時，裂縫流失、假裂縫、對比下降、記憶依賴都對得上真正的 rollout。和 Resampling Forcing 論文（arXiv 2512.15702）的 ablation 結論一致：自回歸重畫優於平行重畫，平行重畫忽略了跨時間的累積。
- S 累積的錯越多，模型越依賴記憶（+0.0027 → +0.0061）。但只用平行重畫訓練時，模型從來沒遇過這種情境。

### 1.2 記憶本身的 exposure bias

v12rfm 訓練時，記憶永遠由真實幀寫成，所以永遠正確；推論時記憶由生成的幀寫成，會帶著灰霧和假裂縫。模型學到「記憶完全可信」，推論時照單全收，就是自我確認。只換 S 解決不了這件事，記憶的來源也要和推論一致。

### 1.3 直接拿 GT 當目標，會和不可逆衝突

S 和記憶帶著模型自己的假裂縫，GT 目標裡卻沒有。直接用 GT 監督，等於教模型擦掉歷史裡已經存在的裂縫。損傷不可逆，這是物理上不可能發生的轉變，也等於教模型「記憶不一定要遵守」。Self Forcing 一系列為此改用分布匹配。rfmv2 保留 GT 目標，但只在這些位置降權。

## 2. 架構

```
                       ┌─────────────── 記憶 M（128×128、1 通道，逐像素對齊）
寫入：每幀 → 細暗結構特徵 → 最近 7 幀取中位數 → 和舊記憶取最暗（只增不減）
                       │
讀取：hint = [ S_{t−1} | s(τ) · M | t_s | h ]  ──→  ControlNet 分支  ──→  v12 主幹  ──→  x_t
              │          │           │     │
              │          │           │     └ 鏈長：S 是最後一張真實幀之後第幾張自己生成的幀，min(h, L)/L
              │          │           └ 重畫強度：S 被重畫時的 t_s（真實幀為 1）
              │          └ 記憶強度：訓練時隨機增益，推論時依去噪階段排程
              └ 前一幀（訓練時為重畫結果，推論時為生成結果）
```

### 2.1 記憶的寫入與存放

| 項目 | 設定 |
|---|---|
| 特徵 | 灰階高通（σ = 2）後的暗結構，門檻 0.15，值 ≤ 0 |
| 持續性 | 最近 7 幀的特徵取中位數才寫入；只閃一兩幀的結構不會進記憶 |
| 單調 | M_t = min(M_{t−1}, 寫入值)，寫入後不會消失（損傷不可逆的先驗） |
| 對齊 | 逐像素，前提是相機固定 |
| 寫入來源 | 訓練：視窗之前用真實幀，視窗內用重畫的幀。推論：生成的幀 |

「持續出現 → 已發生 → 不可逆」由這條寫入規則定義。§3.4 的 loss 遮罩用的也是同一個定義。

### 2.2 記憶的讀取

- **位置：** M 和 S 拼在一起進 ControlNet，同一位置的內容在同一位置被讀到，沒有額外的檢索。
- **強度：**
  - 訓練時，每個樣本的記憶乘上增益 α。以機率 0.25 + 0.5τ 抽 α ~ U[0, 1]，否則 α = 1；另外 10% 的樣本整張記憶歸零。所以在每個去噪時間 τ，模型都看過完整、減弱、沒有記憶三種情況。
  - 推論時用排程 s(τ)：τ 小於切換點用前段值，之後用後段值，數值由掃描決定。
  - 之前在訓練時硬切（v12memg）失敗了：取樣時記憶在切換點突然消失，模型沒看過。隨機增益讓推論時的每一個強度都落在訓練看過的範圍內。
- **空間門控（延後）：** 原本規劃用 32×32 的門控決定逐位置信記憶多少。但 §3.4 的原則是歷史記憶即使是錯的也要遵守，門控在這些位置學不到「不要信」，原本的用途就沒了。留待 ablation。

### 2.3 S 的可信度（兩個通道）

| 通道 | 訓練 | 推論 |
|---|---|---|
| t_s | S 是重畫結果時為該批次的 t_s；真實幀為 1 | 用校準值（初值 0.1：走 h 步 ≈ t_s 0.1 的自回歸重畫），再掃描 |
| h | S 之前連續自己生成了幾張，min(h, L)/L | 第 i 幀的 S 之前生成了幾張：第 0 幀為真實照片時是 i − 1，否則是 i |

時間間隔和損傷增量 Δg 都照實際給，h 只描述 S 的來源。推論時每一幀都從純噪聲生成，字面上 t_s = 0；但那超出訓練分布，所以填的是探測校準出來的等價值。

## 3. 訓練流程

### 3.1 起點與排程

- 從 v12 單幀模型（v12gt 10k）開始，和 v12rfc、v12rfm 相同的起點和 9000 步，結果可以直接比較。
- ControlNet 分支由單幀模型的 encoder 和 mid 複製而來，主幹輸出頭歸零，主幹一起訓練。
- **teacher forcing 暖身：** 前 1000 步不重畫，S 和記憶都用真實幀。之後 1000 步內，重畫視窗的比例從 0 線性升到 1。

### 3.2 訓練單位：視窗

每個樣本是同一條序列（柱子 × 面）中連續的一段：

```
[ 6 張暖機幀 | 錨點 a | 目標 a+1 … a+L ]       L = 8
```

- **暖機幀：** 只用來重建錨點之前的記憶狀態（中位數需要最近 7 幀）。序列開頭不足時留空。
- **錨點：** 錨點本身也會被重畫（讀錨點前一張真實幀）。錨點如果是序列第一幀，就直接用真實照片，對應推論時第 0 幀是真實照片的情況。
- 同一視窗共用水平翻轉、光度增強，以及是否丟掉版面條件。
- 一個 batch 有 128 / L = 16 個視窗，共 128 個目標，和 v12rfm 的 batch 大小相同。視窗在序列和起點上隨機抽，資料順序仍然是隨機的。

### 3.3 自回歸重畫（不傳梯度）

整個 batch 抽一個 t_s = sigmoid(N(−0.5, 1.2))，上限 0.95：

| | v12rfm 的 N(0.5, 1) | rfmv2 的 N(−0.5, 1.2) |
|---|---|---|
| 中位數 | 0.62 | 0.38 |
| t_s < 0.1（對應走 8 步） | 約 0.4% | 約 8% |
| t_s > 0.7（S 大致可信） | 約 42% | 約 13% |

低值要有足夠比例才模擬得出累積誤差；高值也要保留，否則模型會學到 S 永遠不可信，論文稱之為 content drift。

依序處理錨點和其後 L − 1 幀，第 j 幀：

1. 真實的第 j 幀加噪到 t_s：z = (1 − t_s)·ε + t_s·x_j。
2. 從 t_s 積分到 1，讀 [前一張重畫結果 | 目前的歷史記憶 | 可信度]，用第 j 幀的條件、版面和 Δg。solver 用 Euler，8 步涵蓋整個 [0, 1]，實際步數依 t_s 縮短。

   **不要用 Heun。** 第一次訓練（2026-11-10_03-47-29_rfmv2）用了 Heun，重畫出的 S 帶著起始噪聲。Heun 最後一步的第二階段在 t = 1 評估速度，這時網路已經看不到起始噪聲，平均後留下約 ½·dt·z0。重畫每步 dt ≈ 1/8，所以每張 S 帶著約 8 個灰階的白噪聲。以 rfmv2 6k、val 為例（`scripts/eval/heun_hop_check.py`）：

   | t_s | S − x1 和噪聲的相關（Heun / Euler） | 假裂縫（Heun / Euler） | hp_ratio（Heun / Euler） |
   |---|---|---|---|
   | 0.9 | 0.88 / 0.26 | 0.83 / 0.07 | 1.16 / 0.94 |
   | 0.5 | 0.63 / 0.14 | 1.51 / 0.18 | 1.19 / 0.86 |
   | 0.1 | 0.39 / 0.08 | 1.50 / 0.22 | 1.08 / 0.71 |

   原本說「Heun 讓細紋理接近推論」，其實是把殘留噪聲誤當成紋理。最後一步改用 Euler 的 Heun（`cfm_heun_last_euler`）和純 Euler 的結果幾乎一樣，成本卻是兩倍，所以用 Euler。

   後果是模型學會不抄 S 的細結構，見 §7。
3. 用重畫結果更新歷史記憶；同時用真實幀更新另一份真實記憶。
4. 記下第 j + 1 個目標的輸入：S = 這張重畫結果、M = 歷史記憶、可信度 = (t_s, 鏈長)。

一個視窗共 L 次重畫換 L 個目標，平均每個目標一次重畫。成本和 v12rfm 同一量級，只是重畫要依序做 L 次（每次是批次 16 個視窗）。

### 3.4 假記憶遮罩

目標 a + j 的逐像素 loss 權重：

```
允許保留 = 真實記憶寫到目標幀為止有結構 ∪ 目標幀本身有結構     （再膨脹 2 px 容忍位置誤差）
假記憶   = 歷史記憶有結構 ∧ ¬允許保留
權重     = 假記憶處 0.1，其餘 1
```

- 假記憶處不懲罰「保留」，模型照慣性延續已經發生的結構，在物理上是一致的。
- 真實有、歷史沒有的結構（漏掉的裂縫）照常監督，模型要學會補回來。
- 只在 S 上閃一兩幀的錯誤不在記憶裡，照常監督，模型照樣學會修正雜訊。
- 換成學出來的記憶 E 時，同一個定義直接用在記憶空間：歷史記憶場超出真實記憶場的位置。這時「什麼算已經發生、不能推翻」由 E 學出來，也是推廣到一般影片的路徑。

### 3.5 主要 loss

全部 B × L 個目標一起算：

1. S 加上訓練用的小量高斯噪聲；記憶 10% 整張歸零。
2. 組成 hint，乘上記憶增益 α(τ)。
3. CFM：z_τ = (1 − τ)·z_0 + τ·x_t，預測速度 x_t − z_0。patch diffusion 和 min-SNR 權重沿用 v12rfm。
4. 逐像素 MSE 乘上 §3.4 的權重（加權平均）。
5. 加上沿用 v12rfm 的低頻色調 loss（權重 1）。

### 3.6 驗證集

驗證集維持逐幀資料，不切視窗。週期 KID 用完整序列取樣（§4），可信度用推論設定（t_s 通道 0.1）。

## 4. 推論流程

每條序列（柱子 × 面），K 條軌跡：

1. **第 0 幀：**
   - 目前：凍結的 v12 單幀模型生成。
   - 規劃：真實的試驗前照片，先用 RePaint 去掉干擾物（拱形支架等）。真實第 0 幀的效果正在另外評估。
2. **第 i ≥ 1 幀：** 從純噪聲積分（30 步）。
   - S：第 i − 1 幀。
   - M：由第 0 到 i − 1 幀依 §2.1 寫成。
   - 可信度：(t_s 校準值, min(h, L)/L)。
   - 記憶依 s(τ) 縮放。
   - 條件：該幀自己的條件、版面和 Δg。
3. **寫入記憶：** 生成結果寫入記憶，成為下一幀的 S。

所有幀共用同一份低頻起始噪聲，沿用 v12rfm。

## 5. 驗證

| 問題 | 方法 | 期望 |
|---|---|---|
| 推論時有沒有在讀記憶 | 依賴度探測：S 用 rollout 結果，記憶歸零或換成別的樣本的 | 高於 v12rfm 的 3–6% |
| 結構有沒有守住 | rollout 探測：走 h 步後的裂縫保留、假裂縫、拱形物等靜態結構 | 走 8 步時裂縫保留 > 0.61、假裂縫 < 0.53 |
| 整體品質 | KID、灰霧比例、keep@6、lag 24、演進 ratio、型態綜合偏差 | 至少不比 v12rfm 9k 差 |
| 取樣設定 | t_s 校準值和記憶排程 s(τ) 的掃描 | 選出新的預設值 |

## 6. 已知限制

- **灰霧不在這版處理範圍內。** 灰霧只出現在沒看過的柱子上；訓練序列自己 rollout 時全域對比是 1.07–1.09（即使換成平均外觀碼也一樣），所以訓練時的重畫看不到這種漂移。另外，重畫每一跳都從 GT 加噪，低頻被 GT 拉住，也模擬不到低頻漂移。FreqForcing（arXiv 2607.27110）指出，AR 影片的誤差累積主要就是低頻能量漂移。這一塊由推論端處理：真實第 0 幀，以及去噪前段的低頻錨點。
- **訓練序列上的漂移比新柱子小。** 只有 4 × 2 條訓練序列，模型在它們上面 rollout 時的漂移比在 val 上弱（走 8 步：裂縫保留 0.72 vs 0.61，假裂縫 0.18 vs 0.53），所以重畫模擬的累積誤差也偏弱。
- **只適用固定相機。** 推廣到一般影片時，逐像素對齊（相機會動）和單調寫入（物體會變）都要改：讀取改成 attention，寫入改成可學的保留門控。
- **重畫鏈長上限是 L。** 推論時的鏈長會遠超過 8，可信度的鏈長通道在 8 以上一律視為 1。

## 7. 第一次訓練的結果（2026-11-10_03-47-29_rfmv2，重畫用 Heun）

裂縫保留比 v12rfm 差。val、thr 0.08 的 keep@6：6k 為 0.80–0.82（取樣可信度 0.1–0.7），v12rfm 9k 為 0.85。rollout 走 8 步的裂縫保留只有 0.41（v12rfm 0.61）。

S / M 拆解（`scripts/eval/sm_ablation_probe.py`，val，從真實的前一幀生成第 t 幀，數值為裂縫保留）：

| 條件 | rfmv2 6k | v12rfm 9k |
|---|---|---|
| S 真實、M 真實 | 0.587 | 0.785 |
| S 真實、M 歸零 | 0.590 | 0.798 |
| S 換成另一面、M 真實 | 0.392 | 0.350 |
| S 換成另一面、M 歸零（底線） | 0.265 | 0.277 |
| S 模糊 σ = 1 px | 0.550 | 0.662 |

- 問題在 S。只靠條件能畫出的裂縫兩者一樣，但 rfmv2 從 S 得到的裂縫（+0.20）不到 v12rfm（+0.44）的一半，對模糊的 S 也幾乎沒反應。原因是 §3.3 的 Heun 殘留噪聲：訓練時 S 的細結構大多是噪聲。
- 記憶不是原因。兩個模型把記憶歸零後裂縫保留都不變。
- 降權不是原因。暖身後只有約 0.04% 的歷史結構像素被降權（wandb `train/false_mem_frac`）。
- 另外，輸入全是真實時，rfmv2 每步仍壓暗約 6 個灰階（v12rfm +0.8）。這是否也來自噪聲 S，等 Euler 版重訓後再看。

S 變差時記憶有沒有用（`scripts/eval/memory_degraded_probe.py`，val）：S 改用模型自己 rollout 走 h 步的結果，再生成第 t 幀。下表是「推論時的記憶 − 記憶歸零」的差，括號內是「真實幀寫成的記憶 − 記憶歸零」。recover 是 S 已經弄丟的真實裂縫被補回的比例。

| h | v12rfm 9k：keep | v12rfm 9k：recover | rfmv2 6k：keep | rfmv2 6k：recover |
|---|---|---|---|---|
| 1 | −0.002（−0.002） | +0.012（+0.012） | +0.043（+0.044） | +0.045（+0.044） |
| 4 | −0.003（+0.003） | −0.016（+0.002） | +0.045（+0.059） | +0.034（+0.052） |
| 8 | +0.010（+0.020） | −0.004（+0.018） | +0.055（+0.075） | +0.038（+0.065） |

- v12rfm 即使在 S 變差時也不靠記憶。它訓練時的 S 一直可信，記憶也總是由真實幀寫成。
- rfmv2 有在用記憶補裂縫。訓練時的 S 不可信，它學會改靠記憶。不過效果只有 +0.05，比起它和 v12rfm 在 S 上的差距（約 0.2）小得多。
- 推論時的記憶大約拿到乾淨記憶效果的 60–75%（h = 8 時 keep +0.055 vs +0.075）。
- 換成另一面的記憶時，兩個模型的裂縫保留都下降 0.03–0.05。它們確實會讀記憶，只是記憶正確時幫得不多。
- 兩個模型的輸出都隨 rollout 變暗：v12rfm 走 8 步後約 −7 灰階，rfmv2 約 −22。

為什麼記憶用得少（val，記憶由真實幀照 §2.1 寫成，2 px 容忍）：

| 項目 | 數值 |
|---|---|
| 記憶結構占畫面 | 21% |
| 其中第 0 幀就有的靜態結構（網格線、標記） | 88% |
| 損傷記憶占畫面 | 2.7% |
| 損傷記憶涵蓋的損傷裂縫（隨機 18%） | 71%（舊裂縫 75%，新裂縫 40%） |
| 損傷記憶中，前一幀 S 沒有的像素（記憶獨有的資訊） | 6% |
| 這些獨有像素在第 t 幀確實有結構（隨機 15.5%） | 70% |
| ControlNet 輸入層的記憶通道權重（1k → 6k / 9k） | rfmv2 1.48 → 2.76，v12rfm 1.60 → 2.38，和 S 相當 |

- 記憶的內容可靠：舊裂縫大多在裡面，獨有資訊也有 70% 的準確率。網路第一層也確實會讀記憶。
- 問題在冗餘。S 可信時，記憶裡 94% 的損傷結構 S 已經有了，88% 的記憶又是網格線，所以記憶能提供的獨有訊號只占畫面不到 1%。訓練 loss 幾乎沒有理由去學它。
- rfmv2 的 S 比較差，記憶的獨有資訊因此變多，它就學會用一點（+0.05）。
- 推測可能的加劇因素：rfmv2 的記憶增益在去噪後段（細裂縫成形時）有 75% 的機率被隨機縮小，記憶的振幅在這時不可靠。尚未驗證。

## 9. 在 S 上抹除裂縫（rfmv2x，Ring Forcing 的 A-D-R）

§7、§8 的結論：記憶的內容可靠，網路也讀得到，但記憶和 S 高度重複（S 可信時記憶 94% 的損傷結構 S 已經有），訓練 loss 幾乎沒有理由去學記憶。

Ring Forcing（arXiv 2608.26794）的診斷相同：一般影片近期幀就夠預測下一幀，模型學不到從歷史取資訊。它的做法是構造「答案只在歷史裡」的樣本（影片接倒放），再用 context drop（最佳 0.4）控制比例。倒放在這裡不能用（損傷會變少，違反不可逆），所以只取它「出現 → 從近期畫面消失 → 再出現」的結構：

| Ring Forcing | rfmv2x |
|---|---|
| 物體出現過，在歷史裡 | 裂縫已寫進記憶 |
| 近期幀裡消失 | S 裡這條裂縫被抹掉 |
| 目標裡再出現 | 目標裡裂縫仍在（不可逆） |
| context drop 0.4 | `refiner_erase_prob` 0.3 |

做法（`_refiner_erase_cracks`，只在 rfmv2 視窗訓練）：

- 每個目標以機率 `refiner_erase_prob` 抽中（記憶被 drop 的樣本不抽，否則目標無從得知）。
- 抹除範圍：記憶有、目標也有的結構（`memory_feature` < −0.03），扣掉第 0 幀的靜態結構（網格線、標記，dataset `win_static`，膨脹 2 px）。
- 只抹 8 × 8 格中隨機的一部分格子（每個樣本保留率 U[0.5, 1]），所以 S 裡還留著部分裂縫，模型要學的是「S 和記憶互補」，而不是「抽中時全靠記憶」。
- 遮罩膨脹 2 px，用周圍未遮的像素做正規化高斯卷積（σ 3）填補。合成測試：遮罩內的裂縫結構 100% 消失，沒有新增假結構；靠近網格線處填補值偏暗約 0.2，但不會被判成結構。
- S 的其他部分、可信度通道、目標都不變。wandb：`train/erase_frac`（抽中比例）、`train/erase_px`（被抹像素比例）。

訓練：`qsub -v RECIPE=rfmv2,REFINER_ERASE_PROB=0.3,RUN_TAG=rfmv2x job/DamagePatternGeneration/train_ADMCFM_v12refiner.sh`（job 58350），其他設定和 §8 的 Euler 版相同，9k。

期望（和 §8 Euler 9k 比較）：memdeg 的 recover（記憶 − 記憶歸零）在 h = 8 時明顯高於 +0.045；S 真實、記憶歸零時的 keep 下降（模型開始依賴記憶），但 S、記憶都真實時的 keep 不低於 0.633。
